# omo-tps-plus

[English](README.md)

OMO는 에이전트 실행이 끝날 때마다 TPS 한 줄을 띄웁니다. 이 확장은 그 줄을 그대로 두고, 그 실행의 마지막 응답이 시작된 로컬 시각과 프롬프트 캐시 만료 예상 시각을 덧붙입니다.

```
TPS 52.3 tok/s. Cache hit 98.1%, 12.4s. 14:32:05 (~15:32)
```

캐시 수명은 요청할 때마다 다시 시작됩니다. 수명 값은 senpi가 모델별로 계산하는 TTL(`resolvePromptCacheTtlSeconds`)을 씁니다. Claude 구독은 1시간, Anthropic API 키는 5분입니다. senpi가 TTL을 모르는 모델이면 시각만 표시합니다.

세션이 열려 있는 동안에는 화면 맨 아래 상태 줄이 그 수명을 세어 내려가고, 다 되면 알려 줍니다.

```
🔥 52m    캐시가 살아 있음. 남은 분(올림)
🧊        캐시가 만료됨
```

응답이 올 때마다 처음부터 다시 세고, 모델을 바꾸면 지웁니다. 세션을 시작하거나 다시 불러온 뒤 첫 응답이 오기 전, 그리고 senpi가 TTL을 모르는 모델이면 아무것도 표시하지 않습니다.

## 설치

클론 없이 한 줄로 설치합니다. Windows (PowerShell 5.1):

```powershell
irm https://raw.githubusercontent.com/yjacket/omo-tps-plus/master/install.ps1 | iex
```

Linux, macOS:

```sh
curl -fsSL https://raw.githubusercontent.com/yjacket/omo-tps-plus/master/install.sh | sh
```

스크립트가 이 저장소 `master` 브랜치에서 `extension/tps.js`를 받아 `~/.omo/agent/extensions/tps.js`(또는 `OMO_CODING_AGENT_DIR`가 가리키는 폴더)에 덮어씁니다. 파일은 끝까지 다 받은 뒤에 기존 파일과 바꿉니다. OMO가 생성한 연결 파일이나 이전 omo-tps-plus 사본만 교체하고, 다른 파일이면 거부합니다. 클론한 폴더에서 `.\install.ps1`이나 `sh install.sh`로 실행하면 받지 않고 그 폴더의 파일을 복사합니다. 실행 중인 세션에서는 `/reload`를 입력하세요.

Windows에서는 PowerShell 줄을 쓰세요. Git Bash의 curl은 Windows 인증서 저장소를 읽지 않아 인증서 오류(60)로 실패할 수 있습니다.

## 제거

`~/.omo/agent/extensions/tps.js`를 지웁니다. 다음 시작 때 OMO가 기본 연결 파일을 다시 씁니다.

## 업데이트를 따라가는 방식

TPS 수치는 여전히 senpi에 들어 있는 `tps` 확장이 계산합니다. 래퍼는 실행 중인 senpi 패키지에서 그 파일을 불러오므로, senpi를 업데이트하면 이 저장소를 다시 설치하지 않아도 새 버전이 반영됩니다. 래퍼가 하는 일은 실행이 끝날 때 그 확장이 띄우는 알림 끝에 시각과 캐시 만료 시각을 붙이고, 상태 줄 표시를 따로 관리하는 것뿐입니다.

OMO는 `extensions/tps.js`가 `// Generated by` 문구로 시작할 때만 그 파일을 다시 쓰므로, 업데이트해도 래퍼는 그대로 남습니다.

## 한계

- 시각은 마지막 응답이 스트리밍을 시작한 시각으로, 요청을 보낸 시각보다 1~2초 늦습니다. 만료 시각은 분 단위로 내림합니다.
- 만료 시각은 본대화의 TTL을 기준으로 합니다. Claude 구독이 사용 한도를 넘으면 5분으로 줄어드는데, senpi는 이를 알 수 없습니다.
- 상태 줄 표시는 시계만 따라갑니다. 세션이 쉬는 동안 캐시를 되살린 요청(senpi의 `promptCache.keepAlive`, omo-keepwarm)이 있어도 알지 못합니다.
- senpi 업데이트로 `tps` 파일이 옮겨지거나 없어지면 TPS 줄이 사라지고, 세션을 시작할 때 없는 경로를 알려주는 경고가 뜹니다. 제거하면 기본 TPS 줄로 돌아갑니다.

## 개발

```sh
bun test
bun qa/tui-qa.mjs --cwd <dir> --steps qa/steps/turn.json --out .omo/evidence/live
```

QA 스크립트는 실제 OMO를 150x45 터미널에서 띄우고, 프롬프트 하나를 보낸 뒤 화면을 `.ansi`, `.txt`, `.png`로 저장합니다. Chrome과 xterm.js CDN 접속이 필요합니다.
