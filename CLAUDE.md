# CLAUDE.md

This file guides Claude Code (claude.ai/code) in this repository.

## What this is

`extension/tps.js` is an OMO/Senpi extension installed as `<agentDir>/extensions/tps.js` in place of the shim OMO generates for its builtin `tps` extension. It loads that builtin from the running senpi package and appends `. HH:MM:SS, cache till HH:MM` to the notice it posts at `agent_end` (reply start time from the last assistant `message_start`; TTL from pi-ai `resolvePromptCacheTtlSeconds(ctx.model)`, omitted when undefined or throwing). README.md is the user-facing spec; README.ko.md mirrors it with the same headings.

## Commands

```sh
bun test
bun qa/tui-qa.mjs --cwd <dir> --steps qa/steps/turn.json --out .omo/evidence/live
sh install.sh   |   .\install.ps1
```

## Senpi facts this relies on

- `resource-loader.js` `ensureGlobalDefaultExtensions` rewrites `extensions/tps.js` only while it starts with a `// Generated by` banner, and writes it back when the file is missing. The first line of `extension/tps.js` must never start with that banner; the install scripts look for `omo-tps-plus` in it.
- The upstream path mirrors senpi's `getGlobalDefaultExtensionModulePath`: `<getPackageDir()>/core/extensions/builtin/tps.js`, else `<getPackageDir()>/dist/core/extensions/builtin/tps.js`. Sessions run senpi from `~/.omo/agent/runtime/<buildId>/`, so this is the running version.

## Invariants

- Never copy upstream tps logic; only wrap it. `align` pads the three numbers (widths 6, 5, 6; a value longer than its width loses its decimals) only when the line matches `UPSTREAM_SHAPE`; any other shape is appended to unchanged. Upstream reports absurd TPS such as 10653.1 when a short reply arrives in one burst (elapsed 0.0s), so widths must not assume sane values.
- Only `agent_end` handlers get a wrapped context, and only `ui.notify` is changed. Everything else passes through bound to its original object.
- If upstream cannot load, register nothing but one `session_start` warning; never throw from the factory.

## Testing

Tests mock `@code-yeongyu/senpi` and `@earendil-works/pi-ai` with `mock.module` and import a fresh copy with a `?case=` query. Every mock must declare the same keys (`getPackageDir`, `resolvePromptCacheTtlSeconds`): a key absent from the first mock cannot be added by a later one. Use `setSystemTime` for clock values; no sleeps.
